# 唱机 — Local Music Player

[English](README.md)

本地 FLAC 播放器，带本机推荐。扫描电脑上的文件夹，在浏览器里播放，并根据完播 / 跳过学习口味，听歌记录不会上传。

界面是中文。音频文件和播放历史**不在**这个仓库里。

## 功能

- 从本地文件夹读取 FLAC（及其他常见格式），用 Vorbis 标签显示曲名 / 歌手 / 专辑
- 单曲循环、歌手循环、随机、全部循环，以及由模型选下一首的**智能推荐**模式
- 快进快退、倍速（`0.5x`–`2x`）、音量、快捷键
- **为你推荐**：逻辑回归 + Item2Vec + 内容近邻，全部在本机训练
- 可选 macOS 程序坞图标（`npm run install-app`）

## 环境

- Node.js 18+
- 一个音频文件夹（默认 `~/Desktop/music-resources`）
- 只有需要程序坞图标时才要求 macOS；Linux / Windows 用 `npm run dev` / `npm start` 即可

## 开始

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:5173](http://localhost:5173)。生产模式（打包界面 + API）是 [http://localhost:8787](http://localhost:8787)：

```bash
npm run preview
```

曲库目录可改 `config.json` 里的 `musicDir`，或启动时设置环境变量：

```bash
MUSIC_DIR="/path/to/music" npm run dev
```

改完后点侧边栏的「重新扫描」。

在 macOS 上生成本地 **唱机.app**（桌面和 `~/Applications`）：

```bash
npm run install-app
```

第一次会打包界面并打开浏览器；从程序坞退出会关掉后台服务。不要把 `唱机.app` 提交进 Git，它会写入你这台机器上的项目路径。

## 播放

- **单曲循环** / **歌手循环** / **随机播放** / **全部循环**：点播放条右侧的模式按钮切换
- **快进 / 快退 10 秒**：播放键两边的箭头，或键盘 `←` / `→`（Shift 为 30 秒）
- **倍速**：`0.5x`–`2x`，点击倍速按钮循环，悬停可选精确值
- 进度条可拖动；音量滑杆在右下角
- **为你推荐**：完播、跳过和「喜欢」写入 `data/listens.json`（已被 gitignore）并立刻重训
- **智能推荐**播放模式：切到下一首时由模型挑选

## 推荐算法

全部在本机完成。实现见 `server/recommend.js` 与 `server/ml.js`。

### 反馈如何变成标签

每次听完、跳过或点「喜欢 / 不喜欢」都会记一条事件（最多保留 2500 条）。标签规则：

| 行为 | 标签 |
| --- | --- |
| 点喜欢 | 正样本 `1` |
| 点不喜欢 | 负样本 `0` |
| 自然播完，或进度 ≥ 80% | 正样本 `1` |
| 进度 ≥ 55%（未完播） | 弱正 `0.7`，训练时仍当正样本 |
| 进度 < 22% 且听了不到 25 秒 | 负样本 `0`（跳过） |
| 其余 | 忽略，不参与训练 |

「喜欢」还会给该曲额外加完播计数。若只有正样本没有负样本，会从你没听过的歌手里抽几首当负样本，避免模型塌成全 1。

### 每首歌的特征向量（35 维）

| 段 | 维数 | 内容 |
| --- | --- | --- |
| 歌手哈希 | 12 | 歌手名 FNV-1a 哈希到固定槽 |
| 专辑哈希 | 8 | 专辑名同样哈希 |
| 音频数值 | 4 | 时长、`log(1 + 时长)`、采样率、位深 |
| 亲和 | 4 | 该歌手/专辑完播率、歌手播放占比、是否从未听过 |
| 行为 | 4 | 播放次数、跳过率、完播率、最近一次收听的时间衰减 |
| 情境 | 3 | 当前小时的 sin/cos、是否周末 |

### 三个打分器

1. **逻辑回归**（SGD，L2 正则）：用上面的特征预测「你会喜欢这首」的概率 `pLike`。至少 3 条样本且正负都有时才训练；否则 `pLike = 0.5`。
2. **Item2Vec**（16 维 skip-gram）：把听歌记录按 30 分钟无播放切开成 session，窗口 2、负采样 4。完播曲目的向量取平均作为用户向量，再与候选曲做余弦相似度 `seqSim`。
3. **内容近邻**：歌手 + 专辑哈希 + 音频数值组成内容向量。若当前有正在播的种子曲，与候选做余弦相似度 `contentSim`；没有种子时该项为中性 `0.5`。

### 最终分数与多样性

```
score = 0.46 × pLike + 0.24 × seqSim + 0.22 × contentSim
      + 0.08（从未听过）+ 0.12（已点喜欢）− 0.03 × min(播放次数, 6)
```

再按 **MMR** 逐首挑选，避免列表全是同一歌手/专辑：

```
mmr = 0.72 × score − 0.28 × max(与已选曲的内容相似度)
```

侧边栏「为你推荐」默认取 12 首。「智能推荐」切下一首时用同一套分数，取前 6 名里的第一首。卡片上的文案（同一歌手、连着听、口味匹配百分比等）按 `pLike`、序列相似度和内容相似度哪一项更突出来写。

冷启动：还没听够时模型不训练，列表仍可按内容相近和轻微新颖度排序，界面会提示先听几首。

## 隐私

- 没有账号、没有统计、没有远程推荐接口。听歌记录只存在本机 `data/listens.json`。
- HTTP 服务默认绑定 **127.0.0.1**，曲库不会暴露到局域网。只有你明确要在可信网络里分享时，才设置 `HOST=0.0.0.0`。
- 能访问这个进程的人就可以调用 `/api/library` 和 `/api/stream` 列出并播放本地文件。除非有必要，请保持回环地址。

## 快捷键

| 键 | 功能 |
| --- | --- |
| Space | 播放 / 暂停 |
| ← / → | 快退 / 快进 10 秒 |
| Shift + ← / → | 30 秒 |
| N / P | 下一首 / 上一首 |
| ↑ / ↓ | 音量 |
| M | 静音 |

Safari、Chrome、Firefox 均可直接播放 FLAC。文件名可以是哈希，播放器会读 Vorbis 标签里的曲名、歌手和专辑。
